# CogniPath - Alzheimer Assessment

An academic project exploring AI-assisted Alzheimer disease assessment using medical imaging.

## Technologies
- Python
- PyTorch
- Deep Learning
- Medical Image Processing
- Explainable AI

## Project Overview
The project explores the use of deep learning techniques for analysing brain MRI images and supporting Alzheimer disease assessment.

## Disclaimer
This repository contains a basic demonstration and project description. It is not a clinical diagnostic system.
